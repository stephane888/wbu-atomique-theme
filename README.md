# script pour le generation des fichiers du themes
Ce module permet de mettre en place du js ou scss dans un module drupal ou tout autre environnement.
Avantages :
- il compile les données scss pour en creer un css bcp plus leger
- il respecter la logique de habeuk.com
- Optimisation du code et une meilleur maintenabilité
Inconninets :
- Necesite de connaitre un peu de node
- Une mise en plus plus compliqué
